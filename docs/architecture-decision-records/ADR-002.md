# ADR-002: Dense-Only Local Project Engine

## Status

Accepted. Supersedes the backend-selection design.

## Decision

Simgrep uses one dense retrieval engine: sentence-transformer embeddings plus USearch vectors, with DuckDB metadata and lexical term tables for hybrid ranking.

## Consequences

- No PyLate backend.
- No backend enum or resolver.
- No full-rebuild-only backend path.
- No global project registry.
- Local project state lives under `.simgrep/`.

This keeps the product focused on local semantic grep while preserving incremental indexing, ephemeral search, freshness checks, hybrid ranking, and machine-readable output.
